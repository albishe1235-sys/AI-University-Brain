
# AI University Brain

An intelligent university knowledge platform.

## Project Idea
AI University Brain helps university students find information from lecture files and university resources.

## Main Features
- Upload and read lecture files.
- Extract text from PDF, Word, PowerPoint, Excel, and TXT.
- Store lecture information and metadata.
- Search lectures using keywords.
- Display answers with lecture sources and page numbers.
- User roles: Student, Doctor, and Admin.
- Permission-based access control.

## Technologies
- Python
- Streamlit
- JSON
- File Processing
